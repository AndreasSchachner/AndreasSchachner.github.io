Co-author network

Each circle is a co-author; edges connect authors who have written a paper together. Circle size is proportional to the number of joint papers with me. Hover a node to see the name and joint-paper count. Large collaborations (more than {{ site.data.coauthors.max_collab_authors }} authors) contribute to node counts but not to edges, to keep the layout readable. Drag any node to rearrange the layout.
