{%- comment -%} World map of talks. Joins `_data/talks.yml` (via each entry's `venue_key`) with `_data/venues.yml` (coordinates) at Liquid compile time, serialises the result as inline JSON, and renders a Leaflet map with one marker per venue. Each marker's popup lists every talk at that venue; colour encodes the primary (most-recent) type. Tile provider: CartoDB Positron ("Light, no labels" would be cleaner but keeps country labels for orientation). Attribution is required. {%- endcomment -%}

Where I've spoken
